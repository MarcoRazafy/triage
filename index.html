Que voulez-vous faire ?

Étape 1 Trier Ajouter la colonne « produit » à un fichier brut, en comparant ses EAN aux référentiels. Étape 2 Remplir le modèle Ranger un fichier trié dans le modèle de l'enseigne, un onglet par mois.

Ordre habituel : trier le fichier brut, puis remplir le modèle avec le fichier trié.

1

Référentiels

Un ou plusieurs fichiers : fromage, lait, corps gras, crème. La catégorie est lue dans la colonne segmentation_0.

    2

    Fichier brut

    Le fichier de ventes de l'enseigne à classer. Il n'est jamais modifié : le résultat est un nouveau fichier.

    Aperçu des premières lignes
    3

    Triage

    Chaque ligne reçoit la catégorie de son EAN. Le fichier trié garde toute la mise en forme d'origine.

    Fichier trié

    Le résultat de « Trier », avec sa colonne produit.

    2

    Modèle

    Le modèle vide pour commencer une année, ou le fichier de l'année déjà rempli pour ajouter un mois.

    3

    Correspondance des colonnes

    Chaque colonne du modèle reçoit une colonne du fichier trié. Les choix sont pré-remplis et mémorisés pour chaque format de fichier. La colonne promo (O/N) reste vide : elle se saisit à la main dans Excel.

    Chargez le fichier trié et le modèle pour régler la correspondance.
